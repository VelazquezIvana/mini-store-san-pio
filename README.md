# 🛒 Mini Store | Simulador de Gestión Comercial

**Mini Store** es una aplicación web interactiva desarrollada como propuesta educativa para la **Feria de Ciencias 2026 del Instituto de Educación Superior San Pío de Pietrelcina**, en el marco de la **Tecnicatura Superior en Desarrollo de Software**.

El proyecto simula operaciones habituales de un pequeño negocio y permite comprender cómo la programación puede ayudar a organizar productos, controlar inventarios y registrar ventas.
## 🎯 Objetivo educativo

Demostrar cómo un problema cotidiano puede resolverse mediante un sistema informático.
Mini Store acerca a los visitantes a la lógica de programación a través de una experiencia práctica, en la que cada acción genera cambios visibles dentro del negocio simulado.

## ✨ Funcionalidades
### 📦 Gestión de productos
- Visualización de productos disponibles.
- Consulta de precios y cantidades en stock.
- Identificación de productos con bajo inventario.

### 🛍️ Simulación de ventas
- Selección de productos.
- Cálculo de importes.
- Aplicación de descuentos.
- Actualización del stock después de una venta.

### 📊 Control del negocio
- Registro e historial de ventas.
- Reposición de productos.
- Visualización de indicadores comerciales.
- Seguimiento de movimientos del inventario.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura de la aplicación.
- **CSS3:** diseño visual y adaptación a diferentes pantallas.
- **JavaScript:** lógica de ventas, inventario y cálculos.
- **DOM:** actualización dinámica de productos, indicadores y resultados.

## 🚀 ¿Cómo utilizarlo?

1. Abrir la aplicación web.
2. Explorar los productos disponibles.
3. Seleccionar un producto para simular una venta.
4. Ingresar la cantidad y aplicar descuentos cuando corresponda.
5. Confirmar la operación.
6. Observar cómo cambian el stock y los indicadores del negocio.
7. Consultar el historial de ventas o reponer productos.

## 🎓 Conceptos de programación aplicados

El simulador permite identificar conceptos fundamentales:

| Concepto | Aplicación |
|---|---|
| Variables | Precios, cantidades, descuentos y totales |
| Condicionales | Verificación de stock y validación de operaciones |
| Bucles | Recorrido y visualización de productos |
| Funciones | Cálculo de ventas y actualización de inventario |
| Arreglos y objetos | Representación de productos y ventas |
| Eventos | Interacción con botones y formularios |


## 💡 Alcance

Se trata de un **simulador educativo**, no de un sistema de facturación real. Su finalidad es representar procesos comerciales y mostrar cómo se pueden automatizar mediante programación.
